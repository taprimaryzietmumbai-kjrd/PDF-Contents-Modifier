# PDF Visual Editor

GitHub Pages-ready browser PDF editor.

## Features
- Upload and render PDF locally
- Click existing PDF text to create an editable replacement layer
- Add text
- Add images
- Cover/erase content with white rectangles
- Drag added/replacement objects
- Edit text, font, size, colour, opacity, position and dimensions
- Export a modified PDF

## Important
Existing PDF text is not rewritten internally. The editor places a replacement layer over the original text and exports that layer. For exact destructive replacement of arbitrary PDF objects, a server/native PDF engine is required.
